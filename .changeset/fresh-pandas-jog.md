Add a new `@rejot-dev/thalo/vfs` public API for loading Thalo workspaces from custom filesystem
implementations, applying workspace file changes, and writing files with optimistic concurrency
control. Also add `@rejot-dev/thalo/vfs/workspace` for browser-safe loading into a raw `Workspace`.
Documentation now includes a dedicated VFS guide and updated scripting/README examples.
